# MLOps G23

## Deskripsi
Project praktikum MLOps untuk mempelajari pengelolaan repository, Git workflow, struktur project, dan dasar penerapan MLOps.

## Struktur Project
- `frontend/` : bagian antarmuka aplikasi
- `backend/` : bagian backend aplikasi
- `model/` : model machine learning dan dokumentasinya
- `data/` : penyimpanan data raw dan processed
- `tests/` : file pengujian
- `docs/` : dokumentasi project

## Setup
1. Clone repository
2. Buat virtual environment
3. Install requirements

## Cara Menjalankan
Tambahkan command saat aplikasi/model mulai tersedia.

## Tech Stack
Python, Git, GitHub, Google Colab, dan komponen MLOps lainnya.

## Team
Kelompok G23

## Development Workflow
Gunakan branch fitur, commit yang meaningful, lalu merge ke branch main.
